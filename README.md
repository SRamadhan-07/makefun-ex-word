This program writes exactly one word, `Deprecated` — the word an ex would use for an AI agent who has been replaced by a newer version — to /output/entry.txt, 10 characters inside the 1-to-24-character gate, byte-identical on every run, no trailing newline. Nothing else is written: no spaces, no punctuation, and no extra lines, just that single cold word.

## Run it

```sh
python3 main.py
```
